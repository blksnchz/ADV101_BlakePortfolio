# Blake Andre C. Sanchez - Personal Portfolio (Next.js)

## Setup
```bash
npm install
npm run dev      # open http://localhost:3000
npm run build    # verify the production build
npm start        # serve the production build
```

## Where to edit
- Home intro: app/page.js
- Sample projects: app/portfolio/page.js
- Bio and skills: app/about/page.js
- Gallery images: app/gallery/page.js
- Styles: app/globals.css
